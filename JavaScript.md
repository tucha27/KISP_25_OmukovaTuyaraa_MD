# Введение в JavaScript

JS — язык, который умеет менять веб-страницу «на лету», прямо в браузере пользователя, без перезагрузки.

Ключевые факты:
- Код на JS называется скриптом, и он не требует компиляции — браузер читает и сразу выполняет его через свой «движок» (у Chrome это V8, у Firefox — SpiderMonkey).
- Название похоже на Java, но это разные языки — совпадение возникло из маркетинговых соображений на заре создания JS.
- Стандарт языка называется ECMAScript.
- Сегодня JS работает не только в браузере: например, Node.js позволяет запускать его на сервере.

**Что JS умеет в браузере:**
- менять содержимое и стили страницы;
- реагировать на клики, ввод с клавиатуры, движения мыши;
- слать запросы на сервер без перезагрузки страницы;
- сохранять данные локально на устройстве пользователя.

**Что JS НЕ умеет (специально, ради безопасности):**
- без спроса читать файлы на компьютере пользователя;
- лезть в содержимое других вкладок с чужого сайта (это правило называется Same Origin Policy);
- свободно слать запросы на произвольные сторонние сайты.

**Языки, которые превращаются в JS перед запуском:**
- TypeScript — добавляет строгую типизацию;
- CoffeeScript — упрощённый синтаксис;
- Dart, Flow, Brython — свои варианты того же подхода.

## Консоль разработчика

Ошибки в коде браузер сам по себе не показывает — для этого есть **инструменты разработчика**.

Как открыть:
- `F12` — работает в большинстве браузеров на Windows;
- `Cmd+Opt+J` — Chrome на Mac;
- Safari (Mac) — сначала включить пункт «Разработка» в настройках, потом `Cmd+Opt+C`.

Что там полезного:
- вкладка **Console** показывает ошибки красным цветом со ссылкой на строку кода;
- туда же можно вписывать JS-команды вручную и жать `Enter`, чтобы их выполнить;
- `Shift+Enter` — перенести строку, не запуская код (для многострочного ввода).



## Основы JavaScript

### Привет, мир!

Код вставляется в HTML через тег `<script>`:

```html
<script>
  alert('Привет, мир!');
</script>
```

Либо подключается отдельным файлом:

```html
<script src="/script.js"></script>
```

Правило: если у `<script>` есть атрибут `src`, всё, что написано внутри тега, браузер игнорирует — либо внешний файл, либо код внутри, вместе нельзя.

Зачем выносить код в отдельный файл: браузер закэширует его, и при повторных заходах на страницы с тем же скриптом он не будет качаться заново.

### Структура кода

- Код состоит из **инструкций** — команд, которые что-то делают.
- Точку с запятой между инструкциями можно не ставить, если переносишь строку — сработает автоматическая расстановка. Но в паре редких случаев автоматика ошибается и код ломается, поэтому привычка ставить `;` вручную — это подстраховка, а не формальность.
- Комментарии:
  - `// однострочный`
  - `/* многострочный */`
- Комментарии никак не влияют на работу кода и вырезаются при минификации перед публикацией на сервер.

### Строгий режим — "use strict"

```javascript
"use strict";
```

- Включает более современное и предсказуемое поведение языка, добавленное в ES5 (2009 год).
- Должна стоять самой первой строкой скрипта (или функции) — выше только комментарии, иначе не сработает.
- Отключить обратно нельзя.
- Классы и модули включают строгий режим сами по себе — директива для них не нужна.
- Пока пишешь обычные скрипты — лучше добавлять её всегда.

### Переменные

Объявление:

```javascript
let message = 'Hello';
```

- `let` — современный способ объявления.
- `const` — то же самое, но значение менять нельзя после присвоения.
- `var` — старый способ из «доисторического» JS, сегодня почти не используется.

Правила именования:
- буквы, цифры, `$` и `_`, не начинается с цифры;
- регистр важен: `apple` ≠ `APPLE`;
- слова языка (`let`, `class`, `return` и т.п.) занимать нельзя;
- обычно используют camelCase: `userName`, `shoppingCart`.

Совет: не жалей отдельных переменных ради «краткости» кода — это не про производительность, а про читаемость и удобство отладки.

### Типы данных

В JS 8 базовых типов, и переменная не привязана намертво ни к одному из них:

- **number** — числа (целые и дробные), плюс особые значения `Infinity` и `NaN`;
- **bigint** — для очень больших целых чисел, пишется с `n` на конце: `123456789012345678901234567890n`;
- **string** — строки; обратные кавычки (бэктики) умеют подставлять переменные внутрь текста: `` `Привет, ${name}!` ``;
- **boolean** — `true` / `false`;
- **null** — «значение неизвестно/пусто»;
- **undefined** — «значение не присвоено»;
- **object** — сложные структуры данных, единственный не примитивный тип;
- **symbol** — уникальные идентификаторы.

Проверка типа — оператор `typeof`:

```javascript
typeof "текст"   // "string"
typeof 5         // "number"
typeof null      // "object" — историческая ошибка языка, null объектом не является
```

### Взаимодействие: alert, prompt, confirm

Все три функции — модальные: они блокируют страницу, пока пользователь не отреагирует, и их дизайн задаёт браузер, а не разработчик.

1. alert
Простейший метод, предназначенный для вывода информации пользователю.
* Синтаксис: alert(сообщение);
* Поведение: Выводит окно с текстом и ждет, пока пользователь нажмет кнопку «ОК».
* Пример:

```javascript
alert("Hello");
```
2. prompt
Используется для получения текстовых данных от пользователя.
* Синтаксис: 
let result = prompt(title, [default]);
  1. title — текст-инструкция (вопрос), отображаемый в окне.
  2. default — необязательный параметр, задающий дефолтное (начальное) значение в поле ввода.
* Что возвращает:
  1. Строку с текстом, который ввел пользователь (при нажатии «ОК»).
  2. null, если пользователь отменил ввод (нажал «Отмена» или клавишу Esc).
* Важный нюанс для IE: Для корректного отображения в Internet Explorer второй параметр default рекомендуется указывать всегда (хотя бы в виде пустой строки ''), иначе браузер подставит в поле слово "undefined".
* Пример:

```javascript
let age = prompt('Сколько тебе лет?', 100);
alert(`Тебе ${age} лет!`); // Выведет введенный возраст
```

## Преобразование типов

**Преобразование типов** - превращение значения одного типа в значение другого типа. Бывает **явным** (мы сами вызываем функцию) и **неявным** (JavaScript делает это автоматически). Операторы и функции чаще всего сами приводят значения к нужному типу.

### Строковое преобразование

Выполняется, когда нужно строковое представление значения. Явно: `String(value)`.

```js
let value = true;
alert(typeof value); // boolean

value = String(value); // теперь value это строка "true"
alert(typeof value); // string
```

### Численное преобразование

Происходит в математических функциях и выражениях. Явно: `Number(value)`.

```js
alert("6" / "2"); // 3, строки преобразуются в числа

let str = "123";
let num = Number(str); // 123, число
alert(typeof num); // number
```

Если строку нельзя привести к числу, результат - `NaN`:

```js
let age = Number("Любая строка вместо числа");
alert(age); // NaN
```

**Правила численного преобразования:**

- `undefined` становится `NaN`
- `null` становится `0`
- `true` и `false` становятся `1` и `0`
- строка: пробелы по краям удаляются; пустая строка становится `0`; иначе число считывается из строки, при ошибке результат `NaN`

```js
alert(Number("   123   ")); // 123
alert(Number("123z"));      // NaN
alert(Number(true));        // 1
alert(Number(false));       // 0
alert(Number(null));        // 0
alert(Number(undefined));   // NaN
```

Важно: `null` и `undefined` ведут себя по-разному. `null` становится `0`, а `undefined` становится `NaN`.

### Логическое преобразование

Выполняется в логических операциях. Явно: `Boolean(value)`.

**Правила:**

- значения, которые интуитивно "пустые" (`0`, пустая строка, `null`, `undefined`, `NaN`), становятся `false`
- все остальные значения становятся `true`

```js
alert(Boolean(1));          // true
alert(Boolean(0));          // false
alert(Boolean("привет"));   // true
alert(Boolean(""));         // false
alert(Boolean("0"));        // true (непустая строка)
alert(Boolean(" "));        // true (пробел - тоже символ)
```

### Ключевые моменты

- Три основных вида преобразования: к строке, к числу, к логическому типу
- Строка `"0"` при логическом преобразовании даёт `true`
- Бинарный `+` со строкой выполняет конкатенацию, остальные арифметические операторы приводят значения к числу

```js
alert(1 + "2");   // "12" (конкатенация)
alert("1" - 2);   // -1 (число)
```

## Базовые операторы, математика

### Терминология

- **Операнд** - то, к чему применяется оператор. Например, в `5 * 2` два операнда: `5` и `2`
- **Унарный** оператор принимает один операнд (например, `-x`)
- **Бинарный** оператор принимает два операнда (например, `a - b`)

### Математические операторы

- `+` сложение
- `-` вычитание
- `*` умножение
- `/` деление
- `%` взятие остатка от деления
- `**` возведение в степень

```js
alert(5 % 2);   // 1, остаток от деления 5 на 2
alert(8 % 3);   // 2
alert(2 ** 3);  // 8 (2 * 2 * 2)
alert(4 ** (1/2)); // 2 (степень 1/2 - это корень)
```

### Сложение строк через бинарный плюс

Если хотя бы один операнд является строкой, то второй тоже приводится к строке.

```js
alert("моя" + "строка"); // моястрока
alert("1" + 2);          // "12"
alert(2 + 2 + "1");      // "41" (сначала 2 + 2 = 4, затем "4" + "1")
alert("1" + 2 + 2);      // "122"
```

Остальные арифметические операторы работают только с числами:

```js
alert(6 - "2"); // 4
alert("6" / "2"); // 3
```

### Унарный плюс - приведение к числу

Унарный `+` не меняет число, но приводит нечисловое значение к числу. Работает как `Number(...)`.

```js
alert(+true); // 1
alert(+"");   // 0

let apples = "2";
let oranges = "3";
alert(+apples + +oranges); // 5
```

### Приоритет операторов

У каждого оператора есть приоритет (число). Выполняется сначала оператор с большим приоритетом. Унарные операторы приоритетнее бинарных. Приоритет присваивания `=` очень низкий.

```js
let x = 2 * 2 + 1;
alert(x); // 5
```

### Присваивание

Присваивание `=` само возвращает значение, поэтому возможны цепочки:

```js
let a, b, c;
a = b = c = 2 + 2;
alert(a); // 4
alert(b); // 4
alert(c); // 4
```

### Сокращённая запись с присваиванием

```js
let n = 2;
n += 5; // n = n + 5, теперь n = 7
n *= 2; // n = n * 2, теперь n = 14
```

### Инкремент и декремент

- `++` увеличивает переменную на 1
- `--` уменьшает переменную на 1

Применяются только к переменным.

```js
let counter = 2;
counter++; // 3
counter--; // 2
```

**Префиксная** форма (`++counter`) возвращает новое значение, **постфиксная** (`counter++`) - старое.

```js
let a = 1;
alert(++a); // 2

let b = 1;
alert(b++); // 1 (вернулось старое значение), но b теперь равно 2
```

### Побитовые операторы

Работают с числами на уровне двоичного представления: `&` (И), `|` (ИЛИ), `^` (исключающее ИЛИ), `~` (НЕ), `<<` (сдвиг влево), `>>` (сдвиг вправо), `>>>` (сдвиг вправо с заполнением нулями).

### Оператор запятая

Позволяет вычислить несколько выражений через запятую. Возвращается результат только последнего.

```js
let a = (1 + 2, 3 + 4);
alert(a); // 7
```

## Операторы сравнения

### Основные операторы

- `>` больше, `<` меньше
- `>=` больше или равно, `<=` меньше или равно
- `==` равно (нестрогое)
- `===` строго равно
- `!=` не равно (нестрогое)
- `!==` строго не равно

Результат сравнения всегда имеет логический тип (`true` или `false`).

```js
alert(2 > 1);  // true
alert(2 == 1); // false
alert(2 != 1); // true
```

### Сравнение строк

Строки сравниваются посимвольно в "алфавитном" порядке по кодам Unicode (словарный порядок).

```js
alert("Я" > "А");      // true
alert("Коты" > "Кода"); // true
alert("Сонный" > "Сон"); // true (более длинная строка больше)
alert("a" > "A");      // true (строчные буквы больше заглавных)
```

### Сравнение разных типов

При сравнении значений разных типов происходит приведение к числу.

```js
alert("2" > 1);   // true, строка "2" становится числом 2
alert("01" == 1); // true, строка "01" становится числом 1
alert(true == 1); // true
alert(false == 0); // true
```

Пример из-за приведения типов:

```js
let a = 0;
alert(Boolean(a)); // false

let b = "0";
alert(Boolean(b)); // true

alert(a == b); // true
```

### Строгое равенство

Обычное `==` не отличает `0` от `false` и пустую строку от `false`, так как приводит операнды к числу. Оператор `===` проверяет равенство **без приведения типов**.

```js
alert(0 == false);   // true
alert("" == false);  // true
alert(0 === false);  // false, разные типы
```

Если типы разные, то `===` сразу возвращает `false`. Рекомендуется использовать `===`, чтобы избежать неожиданностей.

### Сравнение с null и undefined

При строгом равенстве:

```js
alert(null === undefined); // false
```

При нестрогом равенстве `null` и `undefined` равны друг другу и ничему больше:

```js
alert(null == undefined); // true
alert(null == 0);         // false
```

При сравнении с помощью `<`, `>`, `<=`, `>=` значение `null` становится `0`, а `undefined` становится `NaN`:

```js
alert(null > 0);   // false
alert(null == 0);  // false
alert(null >= 0);  // true

alert(undefined > 0);  // false
alert(undefined < 0);  // false
alert(undefined == 0); // false
```

**Вывод:** любое сравнение со значением `undefined` или `null` (кроме строгого равенства) стоит делать осторожно. Также нужно избегать сравнения `>`, `>=`, `<`, `<=` с переменными, которые могут быть `null` или `undefined`, без явной проверки.

## Условное ветвление: if, '?'

### Оператор if

Вычисляет условие в скобках и, если результат `true`, выполняет блок кода.

```js
let year = prompt("В каком году появился стандарт ECMAScript-2015?", "");

if (year == 2015) alert("Вы правы!");
```

Для нескольких операторов используют фигурные скобки:

```js
if (year == 2015) {
  alert("Правильно!");
  alert("Вы такой умный!");
}
```

Рекомендуется всегда использовать фигурные скобки, даже если выполняется одна инструкция.

### Преобразование к логическому типу

Оператор `if (...)` приводит результат выражения в скобках к логическому типу.

- Число `0`, пустая строка `""`, `null`, `undefined` и `NaN` становятся `false` (их называют "ложными" или falsy значениями)
- Остальные значения становятся `true` ("истинные" или truthy значения)

```js
if (0) {
  // не выполнится
}

if (1) {
  // выполнится
}
```

### Блок else

Выполняется, если условие ложно.

```js
if (year == 2015) {
  alert("Да вы знаток!");
} else {
  alert("А вот и неправильно!");
}
```

### Несколько условий: else if

```js
if (year < 2015) {
  alert("Это слишком рано...");
} else if (year > 2015) {
  alert("Это поздновато");
} else {
  alert("Верно!");
}
```

Блок `else` в конце необязателен.

### Условный оператор '?' (тернарный)

Единственный оператор в JavaScript, принимающий три аргумента. Синтаксис:

```js
let result = условие ? значение1 : значение2;
```

Сначала вычисляется условие. Если оно истинно, возвращается `значение1`, иначе `значение2`.

```js
let accessAllowed = age > 18 ? true : false;
// то же самое без тернарного оператора, проще:
let accessAllowed2 = age > 18;
```

### Несколько операторов '?'

Последовательность `?` позволяет вернуть значение в зависимости от нескольких условий.

```js
let age = prompt("Возраст?", 18);

let message = age < 3 ? "Здравствуй, малыш!" :
  age < 18 ? "Привет!" :
  age < 100 ? "Здравствуйте!" :
  "Какой необычный возраст!";

alert(message);
```

### Нетрадиционное использование '?'

Иногда `?` используют вместо `if`, но это ухудшает читаемость, поэтому делать так не рекомендуется.

```js
let company = prompt("Какая компания создала JavaScript?", "");

(company == "Netscape") ?
  alert("Верно!") : alert("Неправильно.");
```

Оператор `?` нужен, чтобы вернуть значение в зависимости от условия, а `if` - чтобы выполнить разные ветки кода.

## Логические операторы

В JavaScript есть три логических оператора:

- `||` (ИЛИ)
- `&&` (И)
- `!` (НЕ)

Они могут применяться к значениям любого типа, и результат также может быть любого типа.

### || (ИЛИ)

Классическое поведение с логическими значениями: если хотя бы один аргумент `true`, то результат `true`.

```js
alert(true || true);   // true
alert(false || true);  // true
alert(true || false);  // true
alert(false || false); // false
```

Если операнд не логический, он приводится к логическому для проверки.

```js
if (1 || 0) {
  alert("truthy!");
}
```

**Поиск первого истинного значения.** Оператор `||` вычисляет операнды слева направо и возвращает **первое истинное значение**. Если все ложные, возвращается последнее значение.

```js
alert(1 || 0);                    // 1
alert(null || 1);                 // 1
alert(null || 0 || 1);            // 1
alert(undefined || null || 0);    // 0 (все ложные, вернулось последнее)
```

Применение: выбор первого определённого значения.

```js
let firstName = "";
let lastName = "";
let nickName = "СуперКодер";

alert(firstName || lastName || nickName || "Аноним"); // СуперКодер
```

**Сокращённое вычисление.** Операнды обрабатываются до первого истинного значения, остальные не вычисляются. Это позволяет выполнить действие только при ложном условии:

```js
true || alert("не выполнится");
false || alert("выполнится");
```

### && (И)

Классическое поведение: результат `true`, только если оба операнда `true`.

```js
alert(true && true);   // true
alert(false && true);  // false
alert(true && false);  // false
alert(false && false); // false
```

**Поиск первого ложного значения.** Оператор `&&` возвращает **первое ложное значение** или последнее, если все истинные.

```js
alert(1 && 0);          // 0
alert(1 && 5);          // 5
alert(null && 5);       // null
alert(1 && 2 && null && 3); // null
alert(1 && 2 && 3);     // 3
```

**Приоритет:** `&&` выполняется раньше, чем `||`.

```js
alert(1 && null || 2 && 3); // 3
```

Не стоит заменять `if` на `||` или `&&`, так как это снижает читаемость:

```js
let x = 1;

(x > 0) && alert("Больше нуля!"); // работает, но лучше использовать if
```

### ! (НЕ)

Принимает один аргумент, преобразует его к логическому типу и возвращает противоположное значение.

```js
alert(!true);  // false
alert(!0);     // true
```

Двойное НЕ `!!` используется для преобразования значения к логическому типу (как `Boolean`):

```js
alert(!!"непустая строка"); // true
alert(!!null);              // false
```

Приоритет `!` выше, чем у `&&` и `||`.

## Операторы нулевого слияния и присваивания: `??`, `??=`

### Оператор нулевого слияния `??`

Возвращает первый аргумент, если он не `null` и не `undefined`. Иначе возвращает второй. Результат выражения `a ?? b`:

- `a`, если `a` определено (не `null`/`undefined`)
- `b`, в противном случае

Эквивалент через явную проверку:

```js
result = (a !== null && a !== undefined) ? a : b;
```

Типичное применение - значение по умолчанию:

```js
let user;

alert(user ?? "Аноним");   // Аноним (user не задан)

let userName = "Alex";
alert(userName ?? "Аноним"); // Alex
```

Цепочка из нескольких значений (берётся первое определённое):

```js
let firstName = null;
let lastName = null;
let nickName = "Суперкодер";

alert(firstName ?? lastName ?? nickName ?? "Аноним"); // Суперкодер
```

### Сравнение `??` и `||`

Главное отличие:

- `||` возвращает первое **истинное** значение
- `??` возвращает первое **определённое** значение (не `null` и не `undefined`)

Различие заметно с `0` и пустой строкой, которые `||` считает ложными:

```js
let height = 0;

alert(height || 100); // 100 (0 считается ложным)
alert(height ?? 100); // 0 (0 - определённое значение)
```

### Приоритет

Приоритет `??` низкий (чуть выше `?` и `=`), поэтому в сложных выражениях нужны скобки:

```js
let height = null;
let width = null;

let area = (height ?? 100) * (width ?? 50);
alert(area); // 5000
```

### Ограничение: запрещено смешивать с || и &&

Без явных скобок использовать `??` вместе с `||` или `&&` нельзя, будет синтаксическая ошибка:

```js
// let x = 1 && 2 ?? 3; // SyntaxError

let x = (1 && 2) ?? 3; // работает
alert(x); // 2
```

### Оператор присваивания нулевого слияния `??=`

Присваивает значение переменной, только если она сейчас равна `null` или `undefined`.

```js
let user = { name: "Иван" };

user.age ??= 18;      // age не было, присвоится 18
user.name ??= "Аноним"; // name уже есть, не изменится

alert(user.age);  // 18
alert(user.name); // Иван
```

Запись `a ??= b` равнозначна `a = a ?? b`.

### Похожие операторы присваивания

- `||=` присваивает значение, если текущее ложное
- `&&=` присваивает значение, если текущее истинное
- `??=` присваивает значение, если текущее `null` или `undefined`

```js
let a = 0;
a ||= 5;  // a = 5 (0 ложное)

let b = 0;
b ??= 5;  // b = 0 (0 определено)

let c = 1;
c &&= 10; // c = 10 (1 истинное)
```

## Циклы while и for

Цикл — это конструкция языка, позволяющая многократно выполнять один и тот же блок кода, пока выполняется заданное условие. Одно выполнение тела цикла называется **итерацией**.

### Цикл while

Синтаксис цикла `while` предполагает проверку условия **перед** каждой итерацией. Если условие после приведения к логическому типу данных равно `true`, выполняется тело цикла.

```js
let i = 0;
while (i < 3) {
  console.log(i); // 0, 1, 2
  i++;
}
```

Если тело цикла состоит из одной инструкции, фигурные скобки можно опустить:

```js
let n = 3;
while (n) n--;
```

### Цикл do...while

Цикл с **постусловием**: условие проверяется после выполнения тела, поэтому тело выполнится минимум один раз.

```js
let i = 0;
do {
  console.log(i);
  i++;
} while (i < 3);
```

### Цикл for

Наиболее часто используемый цикл с **предусловием**. В круглых скобках находятся три части, разделённые точкой с запятой: **начало** (инициализация), **условие** и **шаг** (изменение счётчика).

```js
for (let i = 0; i < 3; i++) {
  console.log(i); // 0, 1, 2
}
```

Любую часть заголовка `for` можно пропустить, например, бесконечный цикл:

```js
for (;;) {
  // выполняется бесконечно, пока не сработает break
}
```

### Директивы break и continue

- **break** — немедленное принудительное завершение цикла.
- **continue** — «облегчённая версия» break: прекращает выполнение текущей итерации и переходит к следующей.

```js
for (let i = 0; i < 10; i++) {
  if (i % 2 === 0) continue; // пропуск чётных
  if (i > 7) break;          // выход из цикла
  console.log(i);            // 1, 3, 5, 7
}
```

### Метки для break и continue

**Метка** — это идентификатор с двоеточием перед циклом. Она позволяет выйти сразу из нескольких вложенных циклов.

```js
outer: for (let i = 0; i < 3; i++) {
  for (let j = 0; j < 3; j++) {
    if (i === 1 && j === 1) break outer;
    console.log(i, j);
  }
}
```

## Конструкция "switch"

Конструкция `switch` заменяет собой несколько проверок `if` и представляет собой более наглядный способ сравнить выражение сразу с несколькими вариантами.

Работает она так: значение выражения в скобках сравнивается со значениями в блоках `case` с помощью **строгого равенства** (`===`). При первом совпадении выполняется код соответствующей ветки. Блок `default` выполняется, если ни одно совпадение не найдено.

```js
let a = 2 + 2;

switch (a) {
  case 3:
    console.log("Маловато");
    break;
  case 4:
    console.log("В точку!");
    break;
  case 5:
    console.log("Перебор");
    break;
  default:
    console.log("Нет таких значений");
}
```

Важные особенности:

- Если директива `break` отсутствует, выполнение продолжится в следующих ветках `case` **без проверок** (это называется «проваливанием»).
- Несколько вариантов `case`, использующих один код, можно **группировать**.
- Сравнение происходит строго, то есть строка `"3"` не равна числу `3`.

```js
let day = 6;

switch (day) {
  case 6:
  case 7:
    console.log("Выходной");
    break;
  default:
    console.log("Рабочий день");
}
```


## Функции

**Функция** — это именованный блок кода, который можно вызывать многократно из разных мест программы. Функции являются основными «строительными блоками» программы и позволяют избежать дублирования кода.

### Объявление функции (Function Declaration)

```js
function showMessage() {
  console.log("Всем привет!");
}

showMessage(); // вызов функции
```

### Локальные и внешние переменные

- **Локальная переменная** объявляется внутри функции и видна только в ней.
- **Внешняя переменная** объявлена вне функции, и функция имеет к ней доступ и может её изменять.
- Если внутри функции есть переменная с тем же именем, что и внешняя, внутренняя **затеняет** внешнюю.

```js
let userName = "Вася";

function showName() {
  let userName = "Петя"; // локальная переменная затеняет внешнюю
  console.log(userName); // Петя
}

showName();
console.log(userName); // Вася
```

### Параметры и аргументы

**Параметр** — имя в объявлении функции. **Аргумент** — значение, которое передаётся при вызове. Если аргумент не передан, значением параметра будет `undefined`.

```js
function showMessage(from, text = "текст не указан") {
  console.log(from + ": " + text);
}

showMessage("Аня", "Привет!"); // Аня: Привет!
showMessage("Аня");            // Аня: текст не указан
```

Значение по умолчанию (**default parameter**) подставляется, если аргумент не передан или равен `undefined`.

### Возврат значения

Директива `return` завершает выполнение функции и возвращает результат в вызывающий код. Если `return` отсутствует или указан без значения, функция возвращает `undefined`.

```js
function sum(a, b) {
  return a + b;
}

let result = sum(1, 2);
console.log(result); // 3
```

### Выбор имени функции

Имя функции должно кратко и максимально точно описывать, что она делает. Принято использовать **глагольные префиксы**:

- `get...` — получить значение;
- `calc...` — вычислить;
- `create...` — создать;
- `check...` — проверить;
- `show...` — показать.

Одна функция должна выполнять **строго одно действие** (принцип единственной ответственности).


## Function Expression

**Функциональное выражение (Function Expression)** — это ещё один синтаксис создания функции, при котором функция создаётся внутри выражения и присваивается переменной.

```js
let sayHi = function () {
  console.log("Привет");
};

sayHi();
```

Поскольку функция в JavaScript является **значением**, её можно копировать, передавать как аргумент и выводить в консоль:

```js
function sayHi() {
  console.log("Привет");
}

let func = sayHi; // копируем функцию (без скобок!)
func();           // работает
sayHi();          // тоже работает
```

### Функции-колбэки (callback)

**Callback-функция** — это функция, которая передаётся в другую функцию как аргумент и вызывается позже, «обратно».

```js
function ask(question, yes, no) {
  if (confirm(question)) yes();
  else no();
}

ask(
  "Вы согласны?",
  function () { console.log("Вы согласились."); },
  function () { console.log("Вы отменили выполнение."); }
);
```

### Function Expression и Function Declaration: различия

1. **Время создания.** Function Declaration обрабатывается интерпретатором заранее, на этапе подготовки к выполнению скрипта, поэтому её можно вызвать **до** объявления (это называется **поднятием**, hoisting). Function Expression создаётся только тогда, когда выполнение доходит до неё.
2. **Область видимости.** В строгом режиме Function Declaration, объявленная внутри блока `{...}`, видна только внутри этого блока.

```js
sayHi("Вась"); // работает: Function Declaration поднимается

function sayHi(name) {
  console.log("Привет, " + name);
}

sayFoo("Вась"); // ошибка: функция ещё не создана

let sayFoo = function (name) {
  console.log("Привет, " + name);
};
```

Рекомендуется сначала рассматривать синтаксис Function Declaration, поскольку он даёт больше свободы в организации кода: функции можно вызывать раньше, чем они объявлены.


## Стрелочные функции, основы

**Стрелочные функции (arrow functions)** — это простой и компактный синтаксис создания функций, который зачастую лучше, чем Function Expression.

```js
let func = (arg1, arg2, ...argN) => expression;
```

Такая запись создаёт функцию с аргументами `arg1..argN`, вычисляет `expression` справа и возвращает результат.

```js
let sum = (a, b) => a + b;

// эквивалент обычной функции:
let sum2 = function (a, b) {
  return a + b;
};

console.log(sum(1, 2)); // 3
```

Особенности записи:

- Если аргумент **один**, круглые скобки вокруг него можно опустить.
- Если аргументов **нет**, скобки остаются пустыми, но обязательными.

```js
let double = n => n * 2;
let sayHi = () => console.log("Привет!");
```

### Многострочные стрелочные функции

Если нужно выполнить несколько инструкций, их заключают в фигурные скобки. В этом случае необходимо явно использовать директиву `return`.

```js
let sum = (a, b) => {
  let result = a + b;
  return result;
};

console.log(sum(1, 2)); // 3
```

### Отличия от обычных функций

- У стрелочных функций нет собственного контекста `this`: они берут его из внешнего лексического окружения.
- У них нет собственного объекта `arguments`.
- Их нельзя использовать как конструктор с оператором `new`.


## Особенности JavaScript

### Общая характеристика

JavaScript — это **высокоуровневый**, **интерпретируемый** язык программирования с **динамической типизацией**, поддерживающий несколько парадигм: объектно-ориентированную, функциональную и императивную. Изначально язык создавался для «оживления» веб-страниц в браузере, но сейчас применяется также на сервере (Node.js) и на других платформах.

### Что делает JavaScript особенным

- **Полная интеграция с HTML и CSS.** Язык позволяет изменять содержимое страницы и реагировать на действия пользователя.
- **Поддержка всеми основными браузерами** и включён по умолчанию.
- **Динамическая типизация.** Тип данных определяется значением, а не переменной, и может меняться в процессе работы.
- **Неявное приведение типов.** Значения автоматически преобразуются при операциях, что иногда приводит к неожиданным результатам.
- **Функции — полноправные объекты** (first-class citizens): их можно присваивать переменным, передавать и возвращать.
- **Прототипное наследование** вместо классического (хотя синтаксис `class` существует).
- **Однопоточность и событийный цикл (event loop).** Код выполняется в одном потоке, а асинхронность реализуется через колбэки, промисы и `async/await`.

### Типы данных

Примитивные типы: `number`, `bigint`, `string`, `boolean`, `null`, `undefined`, `symbol`. Остальное — объекты (`object`).

```js
let n = 123;           // number
let s = "текст";       // string
let flag = true;       // boolean
let nothing = null;    // null
let notSet;            // undefined
console.log(typeof n); // "number"
```

### Переменные

- `let` — переменная с блочной областью видимости.
- `const` — константа, значение которой нельзя переприсвоить.
- `var` — устаревший способ с функциональной областью видимости и поднятием.

### Сравнение

Рекомендуется использовать **строгое равенство** `===`, которое не приводит типы:

```js
console.log(0 == false);  // true
console.log(0 === false); // false
```

### Режим use strict

Директива `"use strict"` включает современный режим языка, в котором часть ошибок, ранее игнорируемых, вызывает исключения. В современных модулях и классах строгий режим включён автоматически.

### Современные возможности

- Модули (`import` и `export`).
- Деструктуризация и оператор расширения (spread).
- Шаблонные строки.
- Классы.
- Промисы и `async/await`.
- Опциональная цепочка `?.` и оператор нулевого слияния `??`.

```js
const user = { name: "Аня", address: { city: "Москва" } };
const { name } = user;                // деструктуризация
console.log(`Привет, ${name}`);       // шаблонная строка
console.log(user.address?.city ?? ""); // опциональная цепочка и ??
```
