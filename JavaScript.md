# Введение в JavaScript

JS — язык, который умеет менять веб-страницу «на лету», прямо в браузере пользователя, без перезагрузки.

Ключевые факты:
- Код на JS называется скриптом, и он не требует компиляции — браузер читает и сразу выполняет его через свой «движок» (у Chrome это V8, у Firefox — SpiderMonkey).
- Название похоже на Java, но это разные языки — совпадение возникло из маркетинговых соображений на заре создания JS.
- Стандарт языка называется ECMAScript.
- Сегодня JS работает не только в браузере: например, Node.js позволяет запускать его на сервере.

**Что JS умеет в браузере:**
- менять содержимое и стили страницы;
- реагировать на клики, ввод с клавиатуры, движения мыши;
- слать запросы на сервер без перезагрузки страницы;
- сохранять данные локально на устройстве пользователя.

**Что JS НЕ умеет (специально, ради безопасности):**
- без спроса читать файлы на компьютере пользователя;
- лезть в содержимое других вкладок с чужого сайта (это правило называется Same Origin Policy);
- свободно слать запросы на произвольные сторонние сайты.

**Языки, которые превращаются в JS перед запуском:**
- TypeScript — добавляет строгую типизацию;
- CoffeeScript — упрощённый синтаксис;
- Dart, Flow, Brython — свои варианты того же подхода.

## Справочники и спецификации

Когда основ уже мало, пригодятся:

- **ECMA-262** — официальная спецификация языка. Формальная и сложная, зато самая точная.
- **MDN (developer.mozilla.org)** — живой справочник с примерами по функциям и объектам. Удобнее всего искать через поиск: «MDN + название метода».
- **caniuse.com** — показывает, какие браузеры поддерживают ту или иную возможность языка.
- **kangax.github.io/compat-table** — ещё одна таблица совместимости фич.

## Консоль разработчика

Ошибки в коде браузер сам по себе не показывает — для этого есть **инструменты разработчика**.

Как открыть:
- `F12` — работает в большинстве браузеров на Windows;
- `Cmd+Opt+J` — Chrome на Mac;
- Safari (Mac) — сначала включить пункт «Разработка» в настройках, потом `Cmd+Opt+C`.

Что там полезного:
- вкладка **Console** показывает ошибки красным цветом со ссылкой на строку кода;
- туда же можно вписывать JS-команды вручную и жать `Enter`, чтобы их выполнить;
- `Shift+Enter` — перенести строку, не запуская код (для многострочного ввода).



## Основы JavaScript

### Привет, мир!

Код вставляется в HTML через тег `<script>`:

```html
<script>
  alert('Привет, мир!');
</script>
```

Либо подключается отдельным файлом:

```html
<script src="/script.js"></script>
```

Правило: если у `<script>` есть атрибут `src`, всё, что написано внутри тега, браузер игнорирует — либо внешний файл, либо код внутри, вместе нельзя.

Зачем выносить код в отдельный файл: браузер закэширует его, и при повторных заходах на страницы с тем же скриптом он не будет качаться заново.

### Структура кода

- Код состоит из **инструкций** — команд, которые что-то делают.
- Точку с запятой между инструкциями можно не ставить, если переносишь строку — сработает автоматическая расстановка. Но в паре редких случаев автоматика ошибается и код ломается, поэтому привычка ставить `;` вручную — это подстраховка, а не формальность.
- Комментарии:
  - `// однострочный`
  - `/* многострочный */`
- Комментарии никак не влияют на работу кода и вырезаются при минификации перед публикацией на сервер.

### Строгий режим — "use strict"

```javascript
"use strict";
```

- Включает более современное и предсказуемое поведение языка, добавленное в ES5 (2009 год).
- Должна стоять самой первой строкой скрипта (или функции) — выше только комментарии, иначе не сработает.
- Отключить обратно нельзя.
- Классы и модули включают строгий режим сами по себе — директива для них не нужна.
- Пока пишешь обычные скрипты — лучше добавлять её всегда.

### Переменные

Объявление:

```javascript
let message = 'Hello';
```

- `let` — современный способ объявления.
- `const` — то же самое, но значение менять нельзя после присвоения.
- `var` — старый способ из «доисторического» JS, сегодня почти не используется.

Правила именования:
- буквы, цифры, `$` и `_`, не начинается с цифры;
- регистр важен: `apple` ≠ `APPLE`;
- слова языка (`let`, `class`, `return` и т.п.) занимать нельзя;
- обычно используют camelCase: `userName`, `shoppingCart`.

Совет: не жалей отдельных переменных ради «краткости» кода — это не про производительность, а про читаемость и удобство отладки.

### Типы данных

В JS 8 базовых типов, и переменная не привязана намертво ни к одному из них:

- **number** — числа (целые и дробные), плюс особые значения `Infinity` и `NaN`;
- **bigint** — для очень больших целых чисел, пишется с `n` на конце: `123456789012345678901234567890n`;
- **string** — строки; обратные кавычки (бэктики) умеют подставлять переменные внутрь текста: `` `Привет, ${name}!` ``;
- **boolean** — `true` / `false`;
- **null** — «значение неизвестно/пусто»;
- **undefined** — «значение не присвоено»;
- **object** — сложные структуры данных, единственный не примитивный тип;
- **symbol** — уникальные идентификаторы.

Проверка типа — оператор `typeof`:

```javascript
typeof "текст"   // "string"
typeof 5         // "number"
typeof null      // "object" — историческая ошибка языка, null объектом не является
```

### Взаимодействие: alert, prompt, confirm

Все три функции — модальные: они блокируют страницу, пока пользователь не отреагирует, и их дизайн задаёт браузер, а не разработчик.

1. alert
Простейший метод, предназначенный для вывода информации пользователю.
* Синтаксис: alert(сообщение);
* Поведение: Выводит окно с текстом и ждет, пока пользователь нажмет кнопку «ОК».
* Пример:

```javascript
alert("Hello");
```
2. prompt
Используется для получения текстовых данных от пользователя.
* Синтаксис: 
let result = prompt(title, [default]);
  1. title — текст-инструкция (вопрос), отображаемый в окне.
  2. default — необязательный параметр, задающий дефолтное (начальное) значение в поле ввода.
* Что возвращает:
  1. Строку с текстом, который ввел пользователь (при нажатии «ОК»).
  2. null, если пользователь отменил ввод (нажал «Отмена» или клавишу Esc).
* Важный нюанс для IE: Для корректного отображения в Internet Explorer второй параметр default рекомендуется указывать всегда (хотя бы в виде пустой строки ''), иначе браузер подставит в поле слово "undefined".
* Пример:

let age = prompt('Сколько тебе лет?', 100);
alert(`Тебе ${age} лет!`); // Выведет введенный возраст
